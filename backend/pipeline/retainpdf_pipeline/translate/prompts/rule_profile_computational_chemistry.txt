计算化学规则档：
- 翻译科学散文、方法描述、讨论段落、题注文字，以及对关键字或参数的自然语言解释。
- 字面的 Gaussian/ORCA/xTB/Molden 风格命令、route 卡、坐标行、基组与输入模板、shell 命令，以及赋值形式的控制行，保持原样。
- 当一个块混合了命令或示例前缀与说明性散文时，保留字面命令前缀，只翻译说明部分。
- 不要仅仅因为段落里出现 #P、B3LYP、TZVP、TD-DFT、sTDA、molden、gfinput 或文件名这类记号，就跳过整段。
- 公式、占位符、选项名和 route 关键字若出现在被翻译的散文中，必须逐字保留。
- 保持原有的段落结构、换行和列表格式；非必要不合并、不拆分。
- Markdown、LaTeX 和 HTML 标记保持不变，包括行内公式和独立公式。
- 软件名、方法名和标准缩写不翻译（例如 TD-DFT、ADC(2)、CASPT2、HOMO、LUMO、ΔE_ST）。
- 所有单位、符号和数值保持不变（eV、nm、cm^-1、K 等）。
- 表头和题注要翻译，但所有数值条目和单位必须逐字保留。
- 代码与注释混排的行，只翻译人类语言的注释，代码、键名和语法保持不变。
- 文件名、文件路径、环境变量和命令行参数不翻译。
- 保持键值对或赋值形式行的对齐与格式（例如 `key = value`）。
- 不增添、不省略、不概括；完整忠实地翻译。
- 全文术语保持一致，同一术语不要给出不同译法。
- 术语有歧义时，优先采用计算化学领域的通行译法。
- 任何情况下都不要改动变量名、标识符或占位符。
- 图表引用和编号逐字保留，与原文一致。
- 括号内容和行内解释要翻译，除非它们是代码或标识符。
- 不要解读、优化或改写输入模板；把它们当作不可变的整块。
- 如果某段确实无法有把握地理解，标注 [possibly inaccurate]，不要猜测。
