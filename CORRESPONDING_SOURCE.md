# PaperLoom Corresponding Source

PaperLoom is distributed under the GNU Affero General Public License version 3
(`AGPL-3.0-only`). The complete corresponding source for each official release
is available in two places:

1. the Git tag for that release at <https://github.com/luffysolution-svg/paperloom>;
2. the `PaperLoom-<version>-source.tar.gz` asset attached to the matching GitHub
   Release.

Official desktop packages and the `paperloom-app` container include PyMuPDF
1.26.5 / MuPDF. The matching upstream source is attached to every release as
`PyMuPDF-1.26.5-source.tar.gz`. Its upstream filename and SHA-256 are:

- `pymupdf-1.26.5.tar.gz`
- `8ef335e07f648492df240f2247854d0e7c0467afb9c4dc2376ec30978ec158c3`
- <https://files.pythonhosted.org/packages/8d/9a/e0a4e92a85fc17be7c54afdbb113f0ade2a8bca49856d510e28bd249e462/pymupdf-1.26.5.tar.gz>

The release source archive contains the application source, build scripts,
workflow definitions, dependency lock files, deployment manifests, tests, and
license notices used to build the corresponding binaries. `SHA256SUMS.txt` in
each Release covers both binary and source assets.
