# PaperLoom v0.2.8 · 同步上游大文件分段阅读、翻译错误归因与精简模型配置

本次版本在完整保留 PaperLoom 个人桌面工作流（应用内更新、Obsidian 导出、Zotero 联动与写回、WebDAV 及本地备份恢复）的基础上，同步了上游 `retain-pdf`（截至 `97f08772e`）的关键稳定性修复与界面收敛。

## 主要变化

- **翻译错误提示与单项重放**：整份文档零产出时汇总最常见的上游错误并正确归因（如 401 鉴权失败标记为不可重试），单项重放调试时复用该任务保存的模型连接配置。
- **大 PDF 分段读取与封面按需加载**：超过 48 MiB 的受保护 PDF 改走 `PDFDataRangeTransport` 与 HTTP `206 Partial Content` 分段加载，不再整份读入内存；书库封面改为按需加载。
- **移除阅读器问答与独立 AI 服务**：与上游一致，移除阅读器内嵌问答面板、`backend/ai` 独立服务及对应桌面打包启动链路，精简安装包体积与运行时开销。
- **模型配置与上游一致（仅保留 PaddleOCR 与 MinerU）**：设置中心 API 区切换为上游单套配置卡片界面，支持 OpenAI Responses (`openai_responses`)、Anthropic (`anthropic`) 协议、思考深度 (`thinking`) 与 OpenCode Go 预设，OCR 仅保留 PaddleOCR 与 MinerU。
- **OCR / 上传 / 排版与术语表修复**：包含流式数页过滤、Paddle 图注误分类修正、MinerU 跨页接续组恢复、OCR 越界坐标微调、Typst 带圈符号与 `@标记` 转义、术语表制表符/分号导入以及 Windows 路径解析修复。
- **完整保留个人集成功能**：桌面端应用内更新（含网关 502/503/504 自动重试与官方资产 API 回退）、Obsidian 导出与设置、Zotero 浏览/导入/写回、WebDAV 与本地全量备份导出/导入恢复均保持不变。

## 本地验证结果

- 前端 `frontend/web` 全量测试 1,493 项通过（0 失败，2 跳过），`@retainpdf/contracts` / `@retainpdf/domain` / `@retainpdf/reader` / `frontend/web` 类型检查全通过。
- 桌面端 `frontend/desktop` 77 项测试、ESLint（0 警告）及打包依赖与前端产物校验全通过。
- 契约与运维门禁（`check_parity.py`、架构检查、Python 依赖同步检查、`.github/scripts/tests` + `ops/release/tests` + `ops/deployment/docker/delivery/tests` 共 132 项）与源码归档校验全通过。
- 本地独立数据目录实测：编译运行真实 `rust_api` 验证 `/health` 与 `/ready` 无 `ai_service`、旧 AI 路由均返回 404；真实 PDF 上传与 `Range: bytes=0-1023` 返回 `206` 逐字节一致；前端 52 MiB PDF 触发分段传输并中止全量下载；本地模拟上游验证 401 错误归因、`openai_responses` (`/v1/responses`) 与 `anthropic` (`/v1/messages`) 探针；Obsidian 设置持久化、Zotero 状态端点及本地备份 ZIP 创建/下载/恢复挂起/取消均端到端通过。
