# PaperLoom v0.3.5

阅读器补齐作者-年份参考文献悬停预览和 PDF 表格复制，并继续收紧 Markdown 复制行为与多用户入口权限。

- 作者-年份引用可悬停预览参考文献并跳转到对应条目。
- PDF 表格支持纯文本、Markdown 和 LaTeX 复制。
- Markdown 普通文本、链接、代码块恢复浏览器原生复制，独立行间公式保留 LaTeX 复制。
- 标准 Markdown 脚注支持内部跳转和返回阅读位置。
- 修复 Zotero 列表请求竞态、凭据库跨进程锁和强制删除任务竞态。

桌面发布提供 Windows x64 安装版和便携版、macOS Apple Silicon DMG、Linux amd64 DEB。附件中的 `SHA256SUMS.txt` 可用于核对下载文件。
