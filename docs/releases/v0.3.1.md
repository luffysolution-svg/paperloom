# PaperLoom v0.3.1 · 全量同步上游 retain-pdf（rpr_fit 渲染引擎、GLM-OCR、重构详情与多用户能力）并修复文件页就地预览

本次版本为 `v0.3.0` 的正式可发布递进版本（修复 Windows 与 Linux 行尾差异导致的 `dist/css/.reader-sources.sha256` 指纹不一致问题），在完整保留 PaperLoom 个人桌面工作流（Obsidian 导出与设置、Zotero 浏览/导入与译文写回、WebDAV 与本地全量迁移备份恢复、桌面端应用内更新与 AGPL-3.0 源码声明）的基础上，全量同步了上游 `retain-pdf` 截至 `97f08772e` 的全部 8 大类功能演进，并修复了书籍详情「文件」页点击单个文件「查看」误跳转阅读器的问题。

## 主要变化

- **书籍详情「文件」页就地预览修复**：点击 `full.md`、`document.v1.json`、`ocr.zip`、`translated.pdf`、`comparison.pdf`、`source.pdf` 等单文件行的「查看」时，改为在当前书籍详情弹窗内打开嵌套 `ArtifactPreview` 预览浮层；关闭或按 `Escape` 后留在「文件」标签页并将焦点归还触发按钮，同时保留组头一键跳转阅读器入口。
- **进度可视化与书籍详情重构**：引入流水线可视化场景（`AssemblyLineScene` 与 HUD）、翻译质量报告面板（`QualityPanel`）、术语/历史/用量标签页与书籍详情交互重构。
- **翻译质量与 Agent 编排**：同步 `retainpdf-base`、`retainpdf-math`、`retainpdf-pipeline`、`retainpdf-translation`、`retainpdf-translation-agent` 5 个 Python 工作区包，支持 3 档翻译质量等级、中文元评论自纠错与 CLI/代码块跳过。
- **全新 `rpr_fit` 排版渲染引擎**：集成 `backend/rendering-engine`（Node + `fontkit` + `mathjax-full`）、标题只缩不放大策略与长文档分段渲染。
- **双栏阅读顺序、PDF 链接迁回与 OCR 恢复（PR #157）**：支持双栏精确阅读序、PDF 内外部链接位置迁回以及 OCR 乱码文本自动回退至源 PDF 文本层。
- **阅读器性能与交互升级**：全高阅读布局、悬浮页码/缩放 HUD、按页优先加载译文块、regions 接口 ETag + gzip 压缩，以及缩放无白屏切换。
- **导出与术语表增强**：支持 Markdown ZIP 打包导出、术语表文件选择/拖拽导入、追加合并与词条检索。
- **三引擎 OCR 与大文件上传**：新增 **GLM-OCR** 支持并完整保留 **PaddleOCR** 与 **MinerU**，支持流式 OCR 与并行翻译，上传上限提升至 512 MiB（MinerU 200 MiB）。
- **服务端多用户与运维架构**：Rust 后端拆分为 14 个工作区 crate，新增多用户认证/管理面板/通知与 `cargo-chef` 分层 Docker 构建、多用户 compose 覆盖配置。
- **跨平台构建与 Windows 稳定性修复**：修复 Windows 进程存活探测、磁盘可用空间查询、上传反斜杠路径穿越校验、合并阅读超长路径 `MAX_PATH` 限制、前端构建脚本目录拷贝兼容性，以及跨平台 CSS 源指纹 CRLF/排序一致性问题。
- **完整保留 PaperLoom 4 项本地能力**：Obsidian 仓库探测/配置/单本及批量导出与 Markdown ZIP 导出、Zotero 本地接口/数据目录浏览/导入与译文写回、WebDAV 与本地全量迁移包（含凭据可选打包与恢复自检）、桌面端应用内更新与便携版热替换。

## 验证结果

- **CI 全门禁验证**：GitHub Actions `rust-workspace`、`python-services`、`backend-standalone`、`desktop-windows`、`packages`、`architecture`、`Desktop Frontend Sync` 与 `frontend`（含 Playwright 布局门禁）全绿。
- **独立数据目录真机端到端验收（10/10）**：编译运行真实 `rust_api`、`retainpdf-pipeline` 与 `rpr-retain.js`，完整验证 `/health` & `/ready`、单用户模式与 3 个 OCR 引擎（`glm_ocr` / `mineru` / `paddle`）、真实 PDF 上传与馆藏、术语表 CRUD、任务产物清单与按需 `side-by-side.pdf` 生成、Obsidian 仓库导出与 Markdown ZIP、Zotero 数据目录浏览与导入、全量迁移备份 ZIP（含 `frontend-config.json`）、批量导出，以及 `rpr_fit` 引擎真机排版输出含中文与行内 LaTeX 公式的 `overlay.pdf`。
