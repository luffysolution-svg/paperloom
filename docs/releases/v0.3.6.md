# PaperLoom v0.3.6

修复 PDF 图片预览和参考文献交互，补齐退出预览、实际引用命中和阅读位置恢复。

- 图片放大预览支持关闭按钮、Esc 和点击遮罩退出。
- 参考文献预览只在命中实际引用字符时出现，并展示完整可滚动信息。
- 参考文献预览支持数字括号、中文括号、作者年份和经过参考文献索引验证的上标引用。
- 跳转参考文献后提供返回引用前阅读位置的操作。
- 保留 PDF 表格、图片和公式复制功能。

桌面发布提供 Windows x64 安装版和便携版、macOS Apple Silicon DMG、Linux amd64 DEB。附件中的 `SHA256SUMS.txt` 可用于核对下载文件。
