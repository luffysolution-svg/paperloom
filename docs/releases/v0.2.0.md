# PaperLoom 0.2.0

可以在首页和阅读器里使用自己已经登录的本机 Agent，也可以连接自己的模型 API。对话输入框提供统一的服务／模型菜单，历史回答保留生成时的服务和模型。

## 新功能

- BYOA 提供与 Agentero 对齐的 16 个 Agent 预设及自定义 ACP。Codex、Claude Code、Pi 等连接组件可在应用内准备，复用用户 CLI 的登录与配置。
- BYOK 支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages，覆盖问答、工具调用、流式回答和翻译。
- 设置页按品牌、安装和连接状态组织服务，常用字段优先，协议、地址和启动参数放在高级设置中。
- 每个对话独立选择服务、模型和 Agent 配置；发送时固定配置，支持取消、重试、分支及历史恢复。
- ACP 文档工具保留原文引用；多轮追问复用证据时，引用继续指向对应文档和页码。

## 实测中修复的问题

- Windows 的扩展路径导致 Node/npm 连接组件安装或启动失败。
- 无参数工具的空 JSON 增量导致 Anthropic 对话中断。
- 默认用户目录和过短时限影响 Agent 的文献阅读；现在使用独立会话目录，并提供独立的 BYOA 时限。
- Pi 将启动信息混入回答、取消被误报为响应中断、跨轮引用缺少跳转锚点。
- 搜索短摘要不足以核实数字、连续引用编号无法点击，以及首次对话的服务选择互相影响。
- 翻译检查将拆分后的续段误判为截断，将按策略保留的作者等内容误报为接口故障。

## 验证范围

在 Windows 上使用本机 Zotero 的英文论文、中文综述和补充材料完成真实 OCR、问答与译文产物验证。真实 Agent 覆盖测试机器上可用的 Codex、Claude Code、OpenCode 和 Pi；其他预设需要自行安装和登录。三种 API 协议使用用户现有的真实 API／网关完成调用。

测试机器的 Paddle Token 未授权，OCR 使用有效的 MinerU；Claude 默认线路曾触及额度限制，后续选择其已配置的 Sonnet 完成验证。本机 Claude 插件的额外登录提示由该 CLI 配置产生。
