# PaperLoom v0.2.5 · 修复应用更新与构建下载 HTTP 504

修复检查更新成功后，下载校验文件或安装包时遇到 GitHub HTTP 504 而无法继续更新的问题。

- 下载遇到 HTTP 502、503 或 504 时，自动尝试同一发布附件的 GitHub 官方资产 API；每个请求最多尝试两次。
- 检查版本遇到上述临时服务错误时，自动重试一次。
- 更新提示区分检查版本、下载校验文件和下载安装包的失败阶段。
- 继续核对安装包大小和 SHA-256；取消下载或传输中断后清理临时文件，保留手动重试入口。
- 测试、三平台桌面打包和 Docker 构建改用 GitHub 官方资产 API 下载固定版本的 Typst，并核对附件大小及可用的 SHA-256 摘要。

本机已通过 77 项桌面测试和 lint，并使用 Electron 网络栈复现原下载地址的 504。修复后的更新器已通过官方 API 完成 236 MB Windows 安装包下载和 SHA-256 校验。正式产物由完整测试及三平台安装验证门禁生成。

v0.2.4 因构建依赖下载的 504 未完成发布，本版本同时包含应用更新修复与构建下载修复。旧版本更新器若仍遇到 504，请从本次 Release 手动下载对应安装包并安装一次，以获得新的下载逻辑。

提供 Windows x64 安装版与便携版、macOS Apple Silicon DMG、Linux amd64 DEB。桌面包未签名，macOS 未公证。

Docker 正式镜像：

```text

ghcr.io/luffysolution-svg/paperloom-web:v0.2.5
```

正式 Docker 镜像沿用 `linux/amd64`。附件包含完整对应源码、匹配的 PyMuPDF 1.26.5 源码、对应源码说明及 SHA-256 校验和。许可为 AGPL-3.0-only，原有 MIT 和第三方许可随包保留。
