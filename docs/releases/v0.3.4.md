# PaperLoom v0.3.4

Markdown 阅读器增加了选区复制、代码块复制、图片查看和下载、脚注跳转以及带来源页码的摘录操作。复制内容会保留公式 TeX，并提供适合粘贴到 Word 的 HTML 格式。

- 修复只选中 MathJax 公式时复制结果为空的问题，并保留跨段复制的换行。
- 设置中的密钥默认加密显示，翻译服务支持拉取模型并筛选选择。
- 移除独立的手动 WebDAV 云端备份入口，WebDAV 继续作为多设备同步方式使用。
- 修复批量删除工具栏溢出，统一 Zotero 导入和 Markdown 操作按钮的界面样式。

桌面下载提供 Windows x64 安装版和便携版、macOS Apple Silicon DMG、Linux amd64 DEB。附件中的 `SHA256SUMS.txt` 可用于核对下载文件。
