# PaperLoom v0.1.12

本版增加资料库迁移和备份，并适配上游的分页、上传、队列与数据库升级修复。

## 新增

- 设置中的“数据与备份”：导出／导入资料库 ZIP，包含文献文件、书库、合集、收藏批注、问答与术语表。模型密钥和 Agent 配置可选择是否携带。
- 手动 WebDAV 备份、查看备份和恢复。恢复先校验并暂存，重启后生效，保留恢复前数据；重启前可取消恢复。

## 修复与改进

- 搜索及合集按页获取文献，修复超过一页或 500 篇时遗漏文献。
- 普通 PDF 上传边接收边写盘并计算哈希，减少大文件上传占用的内存。
- Windows／Unix 数据盘空间不足时拒绝新上传与任务，并显示中文提示。
- 等待执行的任务使用 FIFO 顺序，队列满时提示稍后重试。
- 旧数据库升级前保存快照，并在事务中检查和补列，避免多个进程同时升级失败。
- 限制过大的任务并发、批量、DPI 和超时参数；保留 PaperLoom 既有的 DeepSeek 并发默认值。
- MinerU 官方下载域名发生 TLS EOF 时可刷新 DNS 后恢复下载，继续验证 HTTPS 证书，并复用已有 OCR 回执。

## 升级与验收

本版所有桌面包、Docker 镜像和对应源码统一使用 `0.1.12`。恢复前建议先导出一份资料库 ZIP；携带密钥的迁移包以明文保存密钥，应存放在可信位置。

已完成 522 篇馆藏分页、32MB 流式上传、一页真实 OCR／模型翻译和 PDF 输出、FIFO／资源限制、四进程旧库升级，以及本机独立 WebDAV 服务的备份和重启恢复测试。用户自己的远端 WebDAV 网盘验收留待用户完成。
