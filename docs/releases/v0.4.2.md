# PaperLoom v0.4.2

- Added the desktop Settings panel for MCP and Skills.
- Added project/global installation scope selection.
- Added Codex, Claude Code, and Pi selection with an all-agents option.
- Added MCP-only and Skills-only installation switches.
- Packaged the MCP bridge and canonical Skills with the desktop backend.
- Added confirmation and status feedback for installation results.
- Removed preconfigured local host files from the repository so fresh installs can be verified through the installer.

The installer uses the bundled PaperLoom CLI for runtime MCP startup. npm/npx remains an optional pinned-version bootstrap path described in the user setup guide.
