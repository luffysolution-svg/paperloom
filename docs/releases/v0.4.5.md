# PaperLoom v0.4.5

## 本次更新

### 阅读器

- 修复实时翻译按钮与目录、搜索入口在小屏和宽屏下的遮挡问题。
- 目录和书内搜索继续以浮动卡片显示在书页上方。
- 保留书内搜索、目录、实时翻译、编辑译文、版本对比、画笔和荧光笔入口。

### MCP 与 Skills

- 设置页重新设计 MCP 与 Skills 工作区，提供运行状态、客户端卡片、安装结果和手动配置区域。
- 支持 Codex、Claude Code、Pi、WorkBuddy、Hermes 五种 Agent 客户端。
- MCP 默认按客户端的全局配置方式安装，Skills 使用共享目录并去重，避免重复安装。
- Windows、macOS、Linux 分别处理配置目录、环境变量、路径和 WorkBuddy 的兼容配置文件。
- 每个客户端都提供可复制的 MCP 配置和启动参数，也支持桌面端一键安装、卸载和连接检查。
- MCP 连接检查会执行 initialize 和 tools/list 握手，配置错误会在设置页显示具体原因。

### 导出与水印

- Word 导出固定不带 RetainPDF 水印或品牌署名。
- PDF 和对照 PDF 继续遵循下载水印策略，`watermark=0` 可获取无水印 PDF。
- Word 导出测试入口兼容 Windows 下的 Node 25，完整 34 项 Word 测试可通过。

### 翻译、OCR 与书库

- 支持精翻 Agent，先通读全书再逐页翻译、审校并统一术语。
- 支持 Anthropic 和 OpenAI 格式接口，兼容 OpenAI 新模型和 OpenCode Go 请求头。
- 新增 GLM-OCR，支持边 OCR 边翻译。
- PaddleOCR、MinerU、GLM-OCR 的页数限制和错误诊断更加明确。
- 支持批量上传、多次翻译版本、模型列表拉取、术语表导入导出、费用估算和用量统计。
- 支持表格翻译试验能力、跨页句子接续、超大文档、书签保留和更快的大书加载。

### 跨平台稳定性

- 修复 Windows 虚拟环境中 Python worker、诊断脚本、`.cmd` 包装器和临时路径的测试兼容性。
- 保留子进程 stderr 尾部诊断，并兼容非 UTF-8 输出。
- 修复 Windows 下连接拒绝、连接超时和 API 探测错误的测试判定。
- Rust workspace 全量测试通过。

## 验证结果

- Rust workspace `cargo test --no-fail-fast --workspace` 全部通过。
- 桌面测试和前端同步验证通过。
- MCP 后端专项测试 17/17 通过。
- Word 导出测试 34/34 通过。
- Windows、macOS、Linux 桌面产物由 tag release workflow 构建并上传。
