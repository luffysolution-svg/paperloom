# PaperLoom v0.2.3 · 精简 AI 接入，保留多协议翻译

本次补丁精简问答接入，恢复原有运行时配置和 OpenAI 兼容调用方式，同时保留独立的多协议翻译与已验证的对话改进。

- 移除通用 BYOA／ACP 连接中心、Agent 预设、适配器准备、认证及权限交互，以及问答侧新增的原生协议和图片输入。
- 翻译继续支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages，服务、模型、凭据和任务配置保持独立。
- 修复阅读器未提供模型 Key 时仍用翻译地址覆盖后端模型配置而导致的 401；Responses／Anthropic 翻译配置也不会误作问答凭据。
- 保留多轮会话、文献范围约束、原文核实、引用跳转、工具进度、用量、停止后保留部分回答、对话搜索和 Markdown 导出。原有 PDF 文档操作能力继续保留。
- 修复翻译协议选择框过窄和窄屏字段跨列裁切，保留续段误报截断及正常保留原文误报接口故障的修复。

本机已完成真实论文问答、引用跳转、流式取消，以及三种协议的实际翻译和 PDF 渲染验收。各协议分别翻译论文前 2 页，最终 PDF 保留原论文 15 页，未解决项与死信数均为零。详见[验收记录](../ops/reports/ai-runtime-simplification-20261108.md)。正式产物由完整测试和安装包验证门禁生成。

提供 Windows x64 安装版与便携版、macOS Apple Silicon DMG、Linux amd64 DEB。桌面包未签名，macOS 未公证。

Docker 正式镜像：

