# PaperLoom v0.2.6 · 修复应用更新 HTTP 504

修复检查更新成功后，下载校验文件或安装包时遇到 GitHub HTTP 504 而无法继续更新的问题。

- 下载遇到 HTTP 502、503 或 504 时，自动尝试同一发布附件的 GitHub 官方资产 API；每个请求最多尝试两次。
- 检查版本遇到上述临时服务错误时，自动重试一次。
- 更新提示区分检查版本、下载校验文件和下载安装包的失败阶段。
- 继续核对安装包大小和 SHA-256；取消下载或传输中断后清理临时文件，保留手动重试入口。
- 构建时通过官方资产 API 获取固定版本的 Typst、Electron、校验文件和打包工具，保留各工具原有的完整性校验，解决同一下载故障对三平台打包的影响。

本机已通过桌面测试和发布工具回归，实测原下载地址返回 504 时可通过官方 API 完成 Windows 安装包下载及 SHA-256 校验。正式产物由完整测试及三平台安装验证门禁生成。

v0.2.4 未完成发布；v0.2.5 已发布 Docker 镜像，桌面构建仍受 Electron 校验文件下载的 504 影响。本版本包含上述应用及构建下载修复。旧版本更新器若仍遇到 504，请手动下载对应安装包并安装一次，以获得新的下载逻辑。

提供 Windows x64 安装版与便携版、macOS Apple Silicon DMG、Linux amd64 DEB。桌面包未签名，macOS 未公证。

Docker 正式镜像：

```text

```
