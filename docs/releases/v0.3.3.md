# PaperLoom v0.3.3

设置中的「同步与备份」现在有三个入口。多设备同步用于在电脑之间同步书库，整库迁移用于导出和恢复资料库 ZIP，数据库快照用于查看和恢复自动或手动保存的数据库版本。已有迁移包可以继续使用。

- 修复 Markdown 和 Obsidian 导出的附件路径检查。新建迁移包会清除数据库快照里的 WebDAV 同步密码。曾向他人分享过旧迁移包并配置过 WebDAV 同步的用户，建议更换对应的应用密码。
- 修复多用户模式下 Zotero 导入的文献归属，同一附件可分别导入不同账号。Docker 部署导出的 Obsidian 笔记支持回到配置的 Web 阅读器地址。
- 桌面端接通同步目录选择、任务通知唤起窗口和数据库快照入口。桌面端与 CLI 共用配置，macOS 和 Linux 可以从设置安装 `paperloom` 命令。
- 修复取消文件保存后下载提示常驻、已保存配置仍提示首次配置的问题，统一 Obsidian 保存和 Zotero 写回弹窗的操作按钮。
- 预构建镜像与源码构建均从部署目录的 `.env` 读取 `PAPERLOOM_API_KEY`。新部署可运行 `python3 init-local.py` 初始化。已有部署可以填入当前私有密钥。

桌面下载提供 Windows x64 安装版和便携版、macOS Apple Silicon DMG、Linux amd64 DEB。附件中的 `SHA256SUMS.txt` 可用于核对下载文件。
