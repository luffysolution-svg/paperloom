# PaperLoom v0.4.0

## Agent integration

- Added `paperloom agent` CLI commands for documents, OCR, translation jobs, Reader context, Zotero, Obsidian, and workflow validation/execution.
- Added a dependency-free local stdio MCP bridge at `paperloom agent mcp`.
- Added versioned Agent envelope, run manifest, and batch workflow contracts.
- Added `paperloom-pdf-ops`, `paperloom-paper-reader`, and `paperloom-paper-search` skills with Codex and Claude Code host configuration.
- Added normalized scholarly search over OpenAlex, Crossref, Semantic Scholar, and Europe PMC with DOI/title deduplication and provider warnings.
- Added batch dry-run, confirmation gates, resumable run directories, and evidence resources.

## Reader

- Removed reference-hover preview, citation click navigation, saved reading-position jumps, and the return-to-citation control.
- Kept ordinary copy, formula LaTeX copy, image actions, table copy, and Markdown reference content.

## Verification

- Rust workspace test binaries compile with `cargo test --workspace --no-run --locked`.
- CLI tests, MCP protocol tests, contracts tests, Reader/Web tests, route manifest tests, and Zotero/Obsidian integration tests pass.
- Real local acceptance covered Zotero status, collection/item listing, attachment import into an isolated PaperLoom data directory, Obsidian vault discovery and managed-note export with cleanup, MCP handshake, and scholarly provider queries.
- A real MinerU OCR submission reached the provider and failed with a retryable upstream TLS handshake error from `cdn-mineru.openxlab.org.cn`. The failure is recorded in the job diagnostics and is not a PaperLoom protocol failure.

Phase 5 ACP in-app chat remains optional and is not included in this release.
