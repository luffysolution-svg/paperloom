# BYOA / BYOK 实现与检查记录

工作起点：PaperLoom `76e191d11`（v0.1.17）。实现范围为 Agentero 当前 16 个 BYOA 预设、自定义 ACP，以及对话和翻译的三种 BYOK 协议。前端使用 Impeccable 的 Operate 指引，保留现有字体、主题、控件与设置中心布局。

## 已实现

- 新增按修订号保存的 AI 连接目录。界面使用「连接」或「保存并验证」完成保存和检测，新连接无需重启 AI 服务；Key 和环境变量值不从新目录接口回传。
- 首页、阅读器共享连接/模型选择器。按会话保存选择，每轮固定快照，历史回答保存来源标签。模型 API 与 OCR/翻译默认值分开；上传翻译也可显式选择同一目录中的 BYOK 连接。
- BYOK 原生支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages，涵盖对话文本、工具往返、流式完成检测，以及 Python/Rust 两条翻译执行路径。
- 翻译协议贯穿 profile、设置、连通性/模型检测、创建任务、Rust 参数校验、阶段 spec、翻译传输、检查点身份、重试及备份。旧配置默认 `openai`。
- 通用 ACP v1 子进程运行层，包含能力协商、认证入口、模型/模式配置、权限与表单、独立取消控制、会话加载和可见历史恢复。
- 本轮文档工具桥接支持 MCP stdio；Pi 使用同一组工具的 CLI 入口。宿主固定文档范围，保留引用与原有 PDF 操作确认流程。
- Windows npm 包入口分别启动 Node 脚本或原生 `.exe`，参数保持独立；继承用户 CLI 的用户目录与认证环境。
- 含凭据的备份加入 `secrets/ai-connections.json`。

原通用 ACP 使用说明已随功能撤回，当前保留的翻译配置见[翻译模型协议](../../core/ai-runtime/TRANSLATION_PROTOCOLS.md)。当时的 Agent 目录来自 [Agentero ecf14d84](https://github.com/poco-ai/Agentero/blob/ecf14d84ab8be59ba54c45f5df83fd015b8ff42f/src-tauri/src/features/agent/registry/templates.rs)，GenericAgent 通过自定义 ACP 接入。

### 全量检查中的既有问题

AI 全量运行记录为 353 通过、20 失败、2 跳过。20 个失败的同名用例均在原始提交的隔离副本中出现；原始副本该组共 22 个失败。主要涉及 FX 的 POSIX 锁与 Unix socket、测试用 Unix 脚本的 Windows 启动方式，以及原有 HTTP 断开时序用例。新增连接使用独立的鉴权取消接口，并有针对性测试。

翻译与阶段 spec 全量运行记录为 1159 通过、11 失败。11 个失败均在原始提交隔离副本中逐项复现。失败涉及 Windows 文件替换/文件锁、POSIX 权限与 `SIGALRM`、`multiprocessing fork`、未安装 Typst，以及既有 replay fixture/冻结哈希。完整日志为本次工作区 `tmp/byoa-translation-tests-final.log`，基线记录为 `tmp/byoa-baseline-translation.log`。

Rust core 全量检查有一个既有 Windows 扩展路径用例失败；worker_command 检查有一个使用 `/specs/...` 字符串后缀的既有 Windows 路径用例失败。`cargo fmt --all -- --check` 也报告了本次未修改文件中的已有格式差异，未扩展改动范围去整理它们。

桌面测试的 lint 通过，66 项测试中 65 项通过；便携版更新用例在清理临时目录时遇到 Windows `EBUSY`。该更新模块未在本次改动中修改。

## AI 服务交互改造

参照 [Agentero 设置说明](https://docs.agentero.app/frontend/settings/#_4) 和其品牌资源，保留 PaperLoom 的设置布局与主题，重做用户指出的两个区域：

- 设置以品牌和状态为入口，已保存服务采用紧凑列表；预设服务只显示必要字段，协议、地址覆盖和 CLI 参数默认折叠。未配置的合成 legacy 条目隐藏，已有浏览器凭据继续兼容。
- 全部 16 个 Agent 具有对应品牌标识；已安装项优先显示。Codex、Claude Code、Pi 和 ZCode 的连接组件可在用户点击连接后自动准备，并显示准备、成功、登录缺失和重试状态。品牌来源与 MIT/CC0 说明已记录。
- 首页和阅读器均改为输入框底栏的单一服务／模型菜单，提供搜索、自定义模型确认和对话设置，移除原生 datalist。菜单打开即聚焦搜索；Escape 关闭菜单并恢复触发器焦点。宿主构建统一 Radix 依赖，避免跨 workspace 的弹窗焦点与指针上下文冲突。
- 模型列表刷新使用 GET `/models`，修正 Chat Completions 地址拼接；修改地址或协议后，不会用已存 Key 获取旧配置的列表。返回编辑页会提醒处理未保存的修改；设置分类切换沿用宿主 forceMount 保留表单。
