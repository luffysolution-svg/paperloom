# AI 接入清理与验收

日期：2026-11-08。工作基线：v0.2.2；问答配置及调用方式参考 v0.1.17。

## 最终功能范围

- 移除通用 BYOA 接入：16 种 Agent 预设、自定义 ACP、适配器准备、连接目录、认证、权限交互、热会话池和活动运行恢复。
- 移除首页、阅读器的逐会话连接选择，以及问答侧 Responses／Anthropic 原生传输和新图片输入。
- 翻译不再读取 AI 连接目录，也不接受 `translation.connection_id`；保留独立的 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 协议。
- 保留原有问答运行时设置、OpenAI 兼容问答、文档操作及旧版实验性 FX 实现。旧 FX 不属于本次新增通用 ACP 接入的删除范围。
- 保留文献范围约束、全文证据核实、连续引用规范化、工具进度、思考与用量展示、取消后的部分回答、会话搜索／导出及滚动改进。
- 保留续段误报截断、正常保留原文误报接口故障的翻译修复，以及发布版本一致性检查。

## 验收中修正的问题

1. 阅读器没有浏览器模型 Key 时，原逻辑仍提交翻译地址和模型，导致后端把自己的模型 Key 发往错误的服务并返回 401。现在省略这一组覆盖值，完整使用后端模型配置；首页与阅读器保持同样的回退规则。
2. Responses／Anthropic 翻译配置不能作为 OpenAI 兼容问答的浏览器凭据覆盖，也不能误解锁问答输入框。旧版 OpenAI 兼容浏览器配置继续可用。
3. 翻译协议类型与名称移至独立公共模块，不依赖已删除的连接目录。
4. 协议选择框恢复完整宽度；窄屏时模型和 Key 的 `div` 字段也改为单列，避免隐式网格列导致内容被裁切。390px 视口中翻译网格及协议选择框均为 291px。
5. 阅读提示词要求围绕当前问题作答、证据足够时结束检索，并按用户需要配图。

## 真实流程

使用本机已有 CGCNN 论文、OCR 产物和有效 API 配置，在独立的数据副本中验收；原始资料库未改写。

- 实际多轮问答核对 Materials Project、46,744 个材料、9,350 个测试晶体，以及 0.039 eV/atom → 39 meV/atom。
- 首页与阅读器均实际发送请求并获得带引用的回答；修复配置覆盖后，阅读器复测成功。
- 点击首页引用，进入 `reader.html`，URL 为 `page_idx=2`，阅读器显示第 3 / 15 页和原文内容。
- 真实 HTTP 流在首段模型正文后断开；后台将 17 字部分回答保存为 `cancelled`，没有丢弃已生成内容。
- 设置页三种协议均可选择，已删除的连接控件数量为零；检查桌面与 390px 窄屏布局。

三种协议分别实际翻译论文前 2 页，随后通过独立渲染任务生成 PDF。每份最终 PDF 保留原论文 15 页；其余 13 页不在本次翻译范围内。
