# WebDAV 修复与备份管理验收

## 修复原因与行为

用户在坚果云配置 `/dav` 根地址时，PROPFIND 返回 207，但直接 PUT ZIP 返回 404。实际创建 `/dav/PaperLoom/` 后，同一账号的 PUT 返回 201，DELETE 返回 204。

现在坚果云根地址会解析为 `/dav/PaperLoom/`，保留用户自定义的其他路径和其他服务商地址。测试连接和上传前发现目标文件夹不存在时，会尝试 MKCOL 创建最终一级目录；父目录必须存在。界面显示实际使用的地址。

新增本地与云端备份删除及分别确认，桌面版打开备份目录、定位指定 ZIP、打开恢复前数据目录，云端文件夹/文件地址复制。上传失败后保留并刷新本地副本，显示具体 HTTP 状态提示。
