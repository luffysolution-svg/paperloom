## 上游新增功能与不宜整体合并的部分

- 多用户账号、登录、会话、数据隔离、管理员后台、邀请码、按页额度、统一 OCR/模型设置。更适合托管服务；当前 PaperLoom 以桌面和自部署为主，暂不建议引入整套账户与配额系统。
- WebDAV/文件夹多设备同步、数据库定时/手动备份与恢复。可以参考其后台任务不随请求断开、短连接测试超时、同步路径限制等做法；数据库备份不能代替全量迁移。
- 翻译准备/复核/精修配置、公式专用包、rpr 渲染引擎修复、文件清单和 reader/regions 扩展。需要用本项目的扫描 PDF、公式及 Obsidian/Word 导出样本回归后再决定；不能覆盖 v0.1.11 的公式修复。
- Rust 领域包大范围拆分改名、58 个旧路由移除、契约生成请求函数、Electron Cordis 生命周期重构。属于架构迁移；直接合并会牵动 Zotero、Obsidian、Agent capability、桌面更新与打包路径，不是本次同步的前置条件。

本项目公开仓库与上游当前没有共同的 Git merge-base；应按功能适配提交，避免整分支合并。

## 本次实现

按用户确认的范围，实现资料库 ZIP 导出/导入、手动 WebDAV 备份/恢复，入口为“设置 → 数据与备份”。

- 数据库使用 SQLite `VACUUM INTO` 生成含已提交 WAL 页的快照；包含文献、合集、收藏批注、问答、术语表等现有表。
- 文件包括 uploads、jobs、documents、assets、operations、fonts、integrations、agent-runtime；每项记录 SHA-256 和大小。
- 模型凭据、Agent 后端配置、Zotero 本地授权文件为可选项；WebDAV 密码留在本机，始终不进入 ZIP。
- 下载缓存、应用程序、外部 Zotero/Obsidian 库、浏览器 localStorage、桌面连接配置不进入迁移包；目标设备的翻译模型选择、主题等本机偏好需要检查。
- 运行或排队中的任务会阻止创建快照/暂存恢复；写请求、流式问答与备份使用同一访问锁，定期清理也遵守该锁。
- ZIP 路径、大小、校验值、格式与数据库版本校验通过后才发布待恢复目录；恢复在下次启动、打开数据库前执行。
- 恢复前的资料保留于 `DATA_ROOT/backups/before-restore/`；通过交换日志和完成标记处理交换过程中断的恢复，不自动清理旧资料。
- 暂存恢复后阻止新写入；用户可取消待恢复操作，或者退出并重启应用/后端完成恢复。
- WebDAV 使用已有文件夹，支持测试连接、列出本应用备份、PUT 上传、GET 下载恢复；传输使用文件流，拒绝跟随重定向，设置和响应不回传密码。

操作说明、API 与范围限制见 [数据备份与迁移](../../core/api/backups.md)。验证结果在该文档末尾记录。
